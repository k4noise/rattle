# Rattle

Сервис для проверки HTTP API некорректными запросами по OpenAPI-схеме. При ошибке целевого сервера сервис старается уменьшить упавший запрос до самого короткого примера, который всё ещё вызывает падение.

## Что считаем падением

- Ответ со статусом `5xx` или обрыв соединения во время ответа, когда сам сервер работает.
- Ответы `4xx` падением не считаются, потому что так API отклоняет неверные данные.
- Если целевой сервер перестаёт отвечать на несколько запросов подряд, проверка останавливается с сетевой ошибкой и не записывает это как падение API.

## Эндпоинты

- `POST /jobs` — запустить проверку
- `GET /jobs/{id}` — статус и прогресс проверки
- `GET /jobs/{id}/crashes` — список найденных падений
- `DELETE /jobs/{id}` — остановить и удалить проверку
- `GET /docs` — Swagger UI

## Выбор коллекций

- `list` — для списка найденных падений и шагов уменьшения запроса, где нужно сохранять порядок элементов.
- `tuple` — для неизменяемого ключа ошибки из метода, пути и кода ответа, чтобы его можно было использовать в `set` и `dict`.
- `dict` — для хранения проверок по `id`, разбора эндпоинтов из схемы и работы с JSON-телом запроса.
- `set` — для отсеивания повторяющихся падений по уже встреченному ключу ошибки.

## Установка и проверка

```bash
uv sync
uv run pytest
uv run mypy src tests
```

Для локальной установки пакета через `pip`:

```bash
pip install -e .
```
